CropGuard

Plant Disease Detection Web Application

Built a web application that analyzes uploaded crop images and provides disease information, severity, treatment suggestions, medicine recommendations and preventive measures.

  • REST endpoint (POST /analyze) with image upload, file type and size validation, and centralized JSON error handling.
  • Multilingual support in 8 Indian languages with text-to-speech for accessibility.
  • Responsive interface built with HTML, CSS, JavaScript and Bootstrap.
  • API key secured with environment variables and a Git-ignored configuration file.
